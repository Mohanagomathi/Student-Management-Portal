# Student Management Portal

## Project Overview
The Student Management Portal is a system designed to manage student information digitally.

## Objectives
- Maintain student records.
- View student details.
- Add new students.
- Update student information.
- Delete student records.

## Methodology
This project follows Agile Scrum methodology.

## Scrum Team Roles
- Product Owner: Defines project requirements and priorities.
- Scrum Master: Helps the team follow Scrum practices.
- Development Team: Plans and develops the portal.

## Project Planning
- Product Backlog: List of project requirements.
- Sprint 1: Project setup and basic student record management planning.
- Version Control: Git and GitHub.

## Technologies
- GitHub for project management and version control.
- HTML, CSS and JavaScript (planned for development).
