
# Sprint 1 Plan — Student Management Portal

## Sprint Duration
1 Week

## Sprint Goal
Set up the project and plan the basic student record management features.

## Selected Backlog Items
- US02: Add student details — 5 points
- US03: View student list — 3 points

Total Planned Story Points: 8

## Sprint Tasks
1. Create the GitHub repository.
2. Prepare the project README.
3. Create and prioritize the Product Backlog.
4. Plan the student data fields.
5. Design a basic student entry form.
6. Plan the student list display.
7. Review the Sprint 1 deliverables.

## Acceptance Criteria

### US02 — Add Student Details
- Student name can be entered.
- Student ID can be entered.
- Email can be entered.
- Required fields are validated.

### US03 — View Student List
- Student records can be displayed in a list.
- Student ID, name and email are visible.

## Expected Deliverables
- GitHub repository created.
- README completed.
- Product Backlog documented.
- Sprint 1 plan documented.
- Basic student form and list design planned.

## Definition of Done
All planned documentation is committed to GitHub and reviewed.
